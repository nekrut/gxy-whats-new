### Highlights

This week, 53 contributors merged 72 pull requests across 26 repositories. Work in the core Galaxy codebase added new file types (RMD, TEI XML), fixed several bugs including dependency injection on Python 3.14 and data source tool redirects, and bumped the default milestone to 26.2. BRC Analytics added organism-specific workflow displays and rebuilt its organism detail page, and galaxy-hub gained new blog and conference content alongside CI workflow infrastructure changes.

## Repository Summaries

### galaxy-hub
This week, the galaxy-hub repository received several automated syncs of training material files and added content related to an upcoming conference, including transportation details, a conference logo on the home page, and poster reordering. A new blog post was created about a "From Pipettes to Code" internship, and content was migrated from the old EU website. On the infrastructure side, CI workflows were migrated to GitHub App authentication, and additional GitHub workflows were restricted to the galaxyproject owner, along with a fix for subdomain table rendering.

### loom
This week, a pull request was merged that makes API error messages from agents more readable for users and removes duplicate entries in the chat interface. A new issue was opened requesting support for pi subagents in Loom and Orbit.

### galaxy
This week, the Galaxy repository merged 12 pull requests that added new file types (RMD and TEI XML), fixed bugs related to shed install column mismatches, data source tool redirects, HDA leaks in tool form for data managers, and dependency injection on Python 3.14, and introduced a unified remove button icon in the upload interface along with a new auto-decompress option in Beta Upload. The default milestone was bumped to 26.2, and the HistoryGraph API received more structured references.

Twenty-one new issues were opened covering topics ranging from the Galaxy v26.1 release publication and a broken linter to UI problems with workflow invocation graphs, notebook previews, FASTA display, BED metadata, and various chat/notebook feature follow-ups. Twelve issues were closed, including fixes for workflow invocation view header wrapping, workflow extraction with cross-history support, Google Drive export failures for

### tools-iuc
This week, the tools-iuc repository updated several tools to newer versions, including page_dewarp (0.2.7 to 0.3.4), fastq_dl (3.0.1 to 4.0.1), selenzy_wrapper (0.3.0 to 0.3.1), psauron (1.1.0 to 1.1.3), and the mapseq dependency manager. Additional pull requests addressed linter warnings and fixes for pureclip, arriba, and multiqc, and changed concoct to use BAI files from metadata. Two new issues were opened: one reporting that hicup fails when genome names contain periods (such as versioned accessions), and another requesting a unique filter for the dada2 taxonomy tool.

### infrastructure-playbook
Two pull requests were merged to fix the GTN (Galaxy Training Network) video proxy location, including a CloudFront-specific fix. One issue was closed related to the Tool Shed search index not updating on the new Tool Shed 2.0 deployment.

### brc-analytics
This week, the brc-analytics repository added support for organism-specific workflows, including displaying them inline on each organism's detail page and removing the previous "Configure Organism" button. The organism detail page table was rebuilt using the useReactTable library instead of the custom DetailViewTable component. User-facing documentation for LMLS workflows was also added, and a new issue was opened to integrate per-species pangenome resources (graphs, chains, signal tracks, and selection data) into the catalog and UI.

### usegalaxy-tools
This week, the usegalaxy-tools repository merged four pull requests: an update to RStudio to Bioconductor version 3.23, the installation of phykit on usegalaxy.org, an update to the tabular learner tool on usegalaxy.org, and a batch update of all tool repositories on 2026-05-20. One new issue was opened reporting an error with the interactive_tool_pavian on UseGalaxy.org.

### galaxy_codex
A broken "Take me back" link that incorrectly pointed to a genome subdomain was fixed to redirect users to the main site. The ruby/setup-ruby dependency was updated from version 1.306.0 to 1.308.0.

### planemo
Two bug fixes were merged: one makes report templates handle null defaults from typed models without breaking, and another escapes rich markup characters in error messages for failed jobs so they display correctly. Two issues were opened about `shed_lint` failing to find required files referenced in tool shed configurations, and one of those was closed during the week.

### training-material
This week, the training-material repository saw updates across several tutorials, including fixes to the Ecoregionalization tutorial (with updated output files and column numbers), corrections to the kMetaShot and MAGs-building tutorials, and an update of VGP (Vertebrate Genomes Project) workflows to their latest versions. The Galaxy Academy 2026 event page was updated to add GAIA Data funding and initiate an ecology/biodiversity track, and contributor/organization metadata was refreshed, including adding a new contributor and the Data Terra logo. Several maintenance tasks were also completed, such as removing duplicate recording metadata, fixing the deploy process, updating cached commit data and persistent URLs, and resolving a text-to-speech issue that was opened and closed within the same week.

### gxformat2
A single dependency update was merged this week, bumping the `idna` package from version 3.11 to 3.15. No other changes were made to the repository.

### galaxy-visualizations
A single pull request was merged this week, adding a test dataset for the "vintent" visualization plugin.

### galaxy-test-data
A single pull request was merged this week, adding a small CSV example dataset containing diabetes data to the test data repository. This provides a new sample file that can be used for testing Galaxy tools and workflows that work with tabular health-related data.

### gravity
This week, the gravity repository updated its CI/CD infrastructure: the Codecov GitHub Action was bumped from version 5 to 6.0.0, several GitHub workflows were improved, and PyPI publishing was switched to use trusted publishing. A separate change set the Celery beat schedule to use its default filename.

### chatgxy-materials
Two pull requests were merged this week. The first added LLM-generated summaries of Intergalactic Workflow Commission (IWC) workflows to the data collection used for the chat assistant. The second added tool help text as an additional data source alongside existing Galaxy Training Network (GTN) and IWC materials.

### galaxy-language-server
The repository updated three server-side dependencies in a single grouped pull request. No other changes were merged this week.

### galaxy-helm
One issue was closed this week related to a Postgres error that occurred when updating Galaxy via Helm from version 5.3.1 to 5.5.0. No other public activity was recorded in the repository during this period.

### ephemeris
A feature request was opened this week proposing a new `--job-conf-tools` option for the `get-tool-list` command, which would allow users to extract tool information from a job configuration file. No other issues or code changes were recorded for the repository this week.
