### Highlights

This week, 54 contributors merged 84 pull requests across 21 repositories and closed 20 issues. Much of the work centered on preparing for the Galaxy Training Academy event and the GCC2026 conference, with updates to event pages, tutorial fixes (particularly for machine learning modules), and new conference content such as posters and talk schedules. The Galaxy server codebase received fixes to the workflow editor, GTN integration routing, and Zenodo/Invenio file source browsing, alongside a new UI component and several newly reported bugs including broken toolbox search and data manager issues in v26. Tool repositories saw a round of version updates across roughly a dozen tools, plus the installation of new tools like Flexynesis and xlsx2tsv.

## Repository Summaries

### gxabm
Two pull requests were merged this week: one adding support for importing Terra workspaces and another adding bootstrap configuration for datasets. Both features had corresponding issues that were opened and closed during the same period.

### usegalaxy-tools
This week, the usegalaxy-tools repository merged eight pull requests. These included routine tool updates (PhysiCell, tabular learner, sklearn_build_pipeline), the installation of Flexynesis tools, the addition of an xlsx2tsv conversion tool, and a bulk update of all repositories dated 2026-05-16. A new issue was opened requesting the download of a GTDB-Tk mock database and its addition to CVMFS.

### loom
Two pull requests were merged this week: one tightening the allowed Node.js version requirements, and another updating the files context menu to select items on right-click and display errors when clipboard operations fail. One issue about a configuration problem was opened and subsequently closed, and a new issue was opened to evaluate using the Agent SDK credit path for Loom's LLM client.

### training-material
This week, the training-material repository saw substantial work related to the GTA (Galaxy Training Academy) event, including updates to the event page with program and certificate information, fixes to multiple machine learning tutorials (Chowell clinical data, flexynesis classification, deep learning), and enhancements to the machine learning module description. Several tutorials across topics were updated: a broken data link was fixed in the climate data tutorial, the taxonomic profiling tutorial was enhanced with Bracken, the Unipept tutorial was updated for a new viewer version, and video recordings were added to two GLEAM tutorials. Infrastructure changes included fixes to the image compression GitHub Action, addition of events to frontmatter linting, and updates to data-library.yaml files and WorkflowHub IDs.

### brc-analytics
This week, the repository merged a pull request that updated the data catalog's generated files to reflect recent changes. Two new issues were opened: one outlining a summer 2026 roadmap and another tracking polish work for the LMLS workflow stepper component.

### galaxy
This week, the Galaxy repository merged fixes ensuring the workflow editor always inserts the latest tool version, restoring GTN (Galaxy Training Network) integration routing, and fixing browsing of own records in Zenodo/Invenio file sources. New functionality included support for file checksums in Zenodo/Invenio and a new GAlert UI component to replace BAlert. Several new issues were filed covering topics such as broken toolbox search with the prebuilt client, data managers not working in v26, Google Drive export failures for filenames containing colons, and missing account activation emails for users who sign up via Google Auth.

### iwc
The repository updated its website dependency Astro from version 6.1.5 to 6.1.10. The SARS-CoV-2 variant calling workflow for paired-end amplicon data was also updated.

### galaxy-hub
This week, the galaxy-hub repository added content for the upcoming GCC2026 conference, including posters, a talk schedule, and fixes to image paths and abstract submission links. Several bug fixes were made to the Galaxy Europe pages, including layout corrections for iframes, citation syncing, and refreshed UI sections. Other changes included importing events and news from the Galaxy Training Network, fixing the image compression workflow, and correcting a contributor ID and registration count on the Swiss SIG page.

### galaxy-helm
This week, the galaxy-helm repository merged two pull requests: one fixing the casing of a connection-proxy-header annotation and another improving the release process. Three issues were closed, covering a bug in the tusd ingress configuration, a question about using CNPG for PostgreSQL, and a topic related to Ingress NGINX retirement.

### pulsar
This week, the Pulsar repository updated its Galaxy job configuration documentation to use YAML syntax and switched its documentation theme to sphinx_rtd_theme. A Docker-related fix pinned the Bookworm base image and restricted wheel file matching to Python 3. A new feature was added to bootstrap pulsar-relay credentials using an OIDC device authorization flow.

### tools-iuc
This week, the tools-iuc repository merged 10 pull requests, all focused on tool updates. Eight tools—rasusa, DIAMOND, vcfanno, tn93, tetoolkit, mgnify_pipelines_toolkit, hicstuff, and gtdbtk—were updated to newer versions, while metamdbg was updated to version 1.4 with new parameters added, and Pretext Map received a new ultra resolution mode. Two new issues were opened: one proposing graceful termination with a fallback mechanism for maxbin2, and one reporting a bug in GTDB-Tk.

### jxtx
A pull request was merged to add an announcement for the GCC 2026 awardee to the JXTX Foundation repository. This was the only change made to the repository this week.

### pulsar-helm
A pull request was merged that adds the ability to disable Docker-in-Docker (DinD) dependencies and toggle the associated service on or off. A new issue was opened requesting sample RBAC (role-based access control) configuration for running Pulsar in Kubernetes job runner mode.

### galaxy-k8s-boot
A GitHub workflow was added to automate the release process for the galaxy-k8s-boot repository. This was the only change merged this week.

### galaxy-language-server
The repository had a single pull request merged this week, which updated three server-side dependencies in a batch version bump. No feature additions, bug fixes, or other changes were made during this period.

### kui
Two issues were reported this week for the Galaxy Project's "kui" repository. One issue noted that history counts appear inflated, and another reported that some charts display as empty when viewing data for any year before 2025.

### ephemeris
A bug was fixed where the `shed-tools` command did not fail when tool installation errors occurred; this issue was closed this week. No other notable activity was recorded in the repository during this period.
